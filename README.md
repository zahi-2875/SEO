# Zahira Shaik — SEO Content Writer | Portfolio

A professional, high-performance portfolio website for Zahira Shaik, an experienced SEO Content Writer, Research Writer, and Content Strategist. Designed with a dark cybernetic neon theme.

## Features

- **About Me**: Brief introduction and writing statistics (Blogs written, Editions published, Years of experience).
- **Featured Writings**: Direct links to selected SEO-driven blog posts with elegant, theme-tailored visual covers.
- **Where I've Written**: Interactive cards displaying writing experience across digital brands, literature anthologies, and magazines.
- **Certifications & Credentials**: Academic credentials and industry-recognized certifications (Hubspot, Semrush, Udemy, Great Learning).
- **Interactive Typing Subheading**: Displays dynamic titles mapping core skills.
- **Collaborative Contact Form**: Features direct social integration and seamless Gmail drafting.

## Technical Details

Built using modern web technologies:
- **Framework**: React (Vite, TypeScript)
- **Styling**: Tailwind CSS & custom cyber-grid systems
- **Animations**: Custom typing hooks and interactive hover reveal effects
